# Сімейний кулінарний помічник — технічні вимоги (Фаза 1)

Джерело: КнигаРецептів.pdf

## Концепція

- Кросплатформовий сервіс: веб + Android зі спільною БД.
- Сімейне використання: рецепти, категорії та плани харчування спільні за замовчуванням.
- Мета: збереження, впорядкування, пошук рецептів; автоматизація меню та шопінгу.

## Зберігання (Фаза 1 — веб)

- Спільні сімейні дані зберігаються в **серверній БД** (Turso / libSQL), доступ через Next.js Route Handlers — не у локальному JSON і не через GitHub Contents.
- Деталі стеку, схеми та API: `Documentation/architecture.md`.

## Функції

1. **Автентифікація** — лише Google; анонімний доступ заборонено.
2. **Видимість** — загальний (default) / приватний.
3. **ШІ-категоризація** — авто-категорія, створення нових, підкатегорії при >10 рецептах.
4. **Імпорт** — URL (сайт, Instagram, Facebook) → стандартизована картка + посилання на джерело.
5. **Картка рецепта** — назва, опис, категорія, автор, приватність, джерело, інгредієнти, кроки, медіа.
6. **Вибране** — персональне; favorites завжди першими в списках.
7. **Пошук** — за інгредієнтами (точний/частковий збіг), глобальний, фільтри, історія.
8. **Планувальник** — тиждень/період, порції з перерахунком, спільний доступ.
9. **Список покупок** — агрегація, категорії магазину, довільні товари, realtime sync.
